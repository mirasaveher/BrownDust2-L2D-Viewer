# BrownDust2 L2D Viewer

An interactive viewer for BrownDust2 character models and animations, featuring Live2D and Spine.

## About the Project

BrownDust2 L2D Viewer is a fan-made project created to explore and showcase character models, animations, and cutscenes from Brown Dust 2.

The project is created and maintained by the administration of the [BrownDust2 Telegram Channel](https://t.me/browndust_2).

## Features

- Browse and view character animations.
- Watch all in-game cutscenes.
- Export animations as WebM videos.
- Export individual animation frames as PNG images.
- Export animations as GIF files.
- Listen to character voice lines.
